# Руководство по импорту данных в Portable Terminal POS

Приложение поддерживает массовый импорт данных из файлов Excel (`.xlsx`, `.xls`). Загрузка производится через вкладку **"Импорт"**.

## Общие правила
1. **Заголовки:** Система автоматически распознает колонки по заголовкам в первой строке. Регистр не важен. Можно использовать как английские, так и русские названия.
2. **Формат данных:** Серийные номера и номера телефонов нормализуются автоматически (удаляются лишние пробелы, тире и спецсимволы).
3. **Обновление:** Если устройство с таким серийным номером уже есть в базе, данные о нем будут обновлены.

---

## 1. Импорт Терминалов и Пинпадов

Этот импорт позволяет быстро наполнить базу оборудованием, привязать к нему SIM-карты и даже сразу "установить" его на объекты.

### Поддерживаемые колонки (заголовки):
| Название (RU) | Название (EN) | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| **Серийный номер** | `serial_number`, `sn` | Да | Уникальный заводской номер устройства. |
| **Модель** | `model` | Нет | Код модели (D230, VX520 и т.д.). Если не указано, определится по Regex-правилам. |
| **Рег. номер** | `registration_number` | Нет | Ваш внутренний инвентарный номер (например, J123456). |
| **Адрес / Объект** | `address`, `installation_place` | Нет | Если заполнено, терминал получит статус **"Установлен"**. |
| **SN Пинпада** | `pinpad_serial_number` | Нет | SN пинпада для автоматической привязки к терминалу. |
| **Номер SIM** | `sim_phone`, `phone` | Нет | Номер SIM-карты, установленной в терминал. |
| **Оператор** | `sim_provider` | Нет | МТС, Билайн, Мегафон, Т2. По умолчанию — МТС. |
| **Комментарий** | `comment` | Нет | Произвольное текстовое описание. |

### Пример таблицы для копирования в Excel:
| serial_number | model | registration_number | address | pinpad_serial_number | sim_phone |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 12345678 | D230 | J100001 | г. Москва, ул. Ленина, 1 | 87654321 | +7 999 123 44 55 |
| 22334455 | VX520 | J100002 | г. Химки, ТЦ "Мега" | | 89001112233 |
| 55667788 | S300 | | | | |

## 2. Импорт SIM-карт

Используется для массовой загрузки сим-карт в справочник или привязки их к уже существующим терминалам.

### Поддерживаемые колонки (заголовки):
| Название (RU) | Название (EN) | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| **Номер телефона** | `phone_number`, `phone` | Да | Номер в любом формате (8..., +7...). |
| **Оператор** | `provider` | Нет | МТС, Билайн, Мегафон, Т2. |
| **SN Терминала** | `serial_number`, `sn` | Нет | Серийный номер терминала, в который вставлена SIM. |
| **Комментарий** | `comment` | Нет | Произвольный текст. |

### Пример таблицы для копирования в Excel:
| phone_number | provider | serial_number | comment |
| :--- | :--- | :--- | :--- |
| 89991234455 | МТС | 12345678 | Основная SIM (М2М) |
| +79001112233 | Т2 | 22334455 | Резервный канал |
| 89160000000 | Билайн | | Свободная SIM на складе |

## Частые вопросы
* **Что если я не укажу модель?** Система попытается определить её по серийному номеру, используя встроенные правила и ваши настройки Regex.
* **Можно ли импортировать пинпады?** Да, точно так же, как терминалы. Система определит, что это пинпад, по его модели.
* **Как привязать SIM к терминалу?** Либо через файл терминалов (колонка `sim_phone`), либо через файл SIM-карт (колонка `serial_number`). Оба способа работают.
